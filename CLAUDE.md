# FORGE — Claude Code Context

## What This Is
FORGE (Factory for Orchestrated Runtime Generation of Engines) is a meta-system that generates full-stack apps from YAML specs. It produces up to 5 layers: Directive (config/prompts), Orchestration (n8n workflow JSON), Execution (FastAPI backend + HTML templates), Scaffold (agent framework), and RALPH (iterative AI build loop).

## Key Files
- `forge.py` — The build engine. All generation logic lives here.
- `specs/coop-briefing.yaml` — The only app spec currently. Defines COOP Morning Briefing.
- `output/` — Generated output (gitignored, regenerated by `python3 forge.py build`).
- `templates/ralph/` — RALPH loop templates (PRD, ralph.sh, progress.txt).
- `templates/agent-workflow-shell/` — Reference agent scaffold.
- `docs/` — Architecture docs, handoff spec, reference manuals.

## Build & Test
```bash
python3 forge.py build specs/coop-briefing.yaml     # Generate layers 1-3 (+ 4/5 if spec has scaffold:/ralph:)
python3 forge.py validate specs/coop-briefing.yaml   # Validate spec only
python3 forge.py list-layers specs/coop-briefing.yaml # Preview what will be generated
python3 forge.py new <name> [description]             # Scaffold-only mode (no YAML spec needed)
python3 forge.py test [project-dir]                   # Run pytest in project directory
python3 forge.py check [project-dir]                  # Run health_check.py
```

## Build Pipeline (5 Layers)
```
spec.yaml -> Forge.build()
               +-- DirectiveGenerator.generate()      -> Layer 1 (always)
               +-- OrchestrationGenerator.generate()   -> Layer 2 (always)
               +-- ExecutionGenerator.generate()        -> Layer 3 (always)
               +-- ScaffoldGenerator.generate()         -> Layer 4 (if spec has scaffold:)
               +-- RalphGenerator.generate()            -> Layer 5 (if spec has ralph:)
               +-- write_manifest()                     -> MANIFEST.json
```

## Layer 4: Scaffold (opt-in)
Generates a complete agent framework: guardrails, confidence scoring, audit logging, cost tracking, health checks, ROI tracking, feature flags, tests, CLAUDE.md, ARCHITECTURE.md, Makefile, config.yaml.

Enable by adding `scaffold: { enabled: true }` to the YAML spec, or use `forge.py new`.

## Layer 5: RALPH (opt-in)
Generates PRD.json (story-based requirements), ralph.sh (Claude Code CLI loop), and progress.txt (append-only log). RALPH iteratively implements stories one per context window.

Enable by adding a `ralph:` section to the YAML spec:
```yaml
ralph:
  enabled: true
  ci_commands:
    - "make test"
  stories:
    - id: "S-001"
      priority: 1
      title: "Project scaffold and config"
      description: "Initialize project structure..."
      acceptance_criteria:
        - "make test runs without errors"
      test_command: "make test"
      depends_on: []
```

If stories are omitted, 3 default foundation stories are generated.

## Architecture Rules
- **output/ is ephemeral** — never hand-edit files there. Fix forge.py instead.
- **n8n connections use node names**, not IDs. Connection keys must match the `name` field on nodes.
- **Webhook nodes need `webhookId`** or n8n namespaces the path and it won't resolve at the short URL.
- **POST sources** (like planner) are called inline in the Code node after merge, not as separate HTTP request nodes. They need upstream data from GET sources.
- **GET sources** become HTTP Request nodes wired through merge.
- **Delivery nodes** reference `$json.subject`, `$json.body`, `$json.voice` — the Code node must produce all of these.

## API Response Shapes
- `/api/triage/inbox` — flat JSON array of `{id, thread_id, subject, sender, snippet, date, importance, reason, suggested_action}`
- `/api/calendar/events` — flat JSON array of `{id, summary, start, end, location, description, all_day}`
- `/api/planner/generate` — POST with `{date, calendar_events[], triaged_emails[]}`, returns `{date, blocks[], top_priorities[], email_actions[], summary}`
- `/api/gmail/send` — POST with `{to, subject, body}`
- `/api/voice/speak` — POST with `{text}`, returns mp3 stream
